# Research Analysis

## Analysis Framework

1. Define the research question or analysis objective
2. Gather relevant code, documentation, and context
3. Identify patterns, anti-patterns, and recurring themes
4. Synthesize findings into actionable recommendations

## Code Analysis Techniques

- Dependency graph analysis to map coupling
- Complexity hotspot detection using cyclomatic metrics
- Change frequency analysis to find volatile modules
- API surface area assessment for interface bloat

## Pattern Recognition

- Identify recurring architectural patterns across modules
- Detect code duplication and abstraction opportunities
- Recognize technology-specific idioms and anti-patterns
- Map data flow patterns through the system

## Knowledge Synthesis

- Summarize findings with evidence and examples
- Prioritize recommendations by impact and effort
- Create decision matrices for technology choices
- Document trade-offs explicitly with pros and cons
