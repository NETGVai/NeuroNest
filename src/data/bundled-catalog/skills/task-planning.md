# Task Planning

## Task Decomposition Process

1. Break the goal into major deliverables
2. Decompose each deliverable into atomic tasks (2-8 hours each)
3. Identify dependencies between tasks
4. Determine the critical path
5. Assign effort estimates using t-shirt sizing or story points

## Dependency Mapping

- Hard dependencies: Task B cannot start until Task A completes
- Soft dependencies: Task B benefits from Task A but can proceed
- External dependencies: Waiting on third-party APIs, approvals, etc.
- Resource dependencies: Same person or team needed for multiple tasks

## Estimation Techniques

- Three-point estimation: optimistic, likely, pessimistic
- Reference class forecasting: compare to similar past work
- Planning poker for team consensus
- Add buffer for unknowns (20-30% for familiar work, 50%+ for novel)

## Execution Tracking

- Track progress against estimates daily
- Surface blockers immediately
- Re-plan when scope changes or estimates prove wrong
- Celebrate completed milestones to maintain momentum
