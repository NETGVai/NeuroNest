# Project Planning

Plan software projects with task decomposition, dependency mapping, and milestone tracking.

## When to Use
- When starting a new project or major feature
- When breaking down epics into actionable tasks
- When estimating effort and setting timelines
- When coordinating work across team members

## Guidelines

### Task Decomposition
- Break work into tasks completable in 1-3 days
- Define clear acceptance criteria for each task
- Identify dependencies between tasks
- Estimate effort using story points or time ranges

### Dependency Mapping
- Map task dependencies as a directed acyclic graph
- Identify the critical path through dependencies
- Parallelize independent tasks for faster delivery
- Flag external dependencies and blockers early

### Milestone Planning
- Define milestones with measurable deliverables
- Set realistic timelines with buffer for unknowns
- Include review and testing phases in the plan
- Track progress against milestones weekly

### Risk Management
- Identify technical risks and unknowns upfront
- Plan spikes for high-uncertainty areas
- Have contingency plans for critical path delays
- Communicate risks and status transparently

## Best Practices
- Involve the team in estimation and planning
- Re-plan when significant changes occur
- Keep plans lightweight and adaptable
- Use retrospectives to improve planning accuracy
