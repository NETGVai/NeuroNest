# Goal Decomposition

## Decomposition Process

1. State the goal in one clear sentence
2. Identify the 3-5 major milestones needed to achieve it
3. Break each milestone into concrete, atomic tasks
4. Define success criteria for each task
5. Map dependencies and identify the critical path

## SMART Task Criteria

- **Specific**: Clearly defined scope and deliverable
- **Measurable**: Quantifiable completion criteria
- **Achievable**: Within the team's capability and resources
- **Relevant**: Directly contributes to the parent goal
- **Time-bound**: Has a realistic deadline or estimate

## Dependency Analysis

- Identify blocking dependencies early
- Parallelize independent task streams
- Flag external dependencies that are outside your control
- Build slack into the schedule for dependency delays

## Progress Tracking

- Track completion percentage at the task level
- Roll up progress to milestone and goal levels
- Surface blocked tasks and stale items daily
- Adjust plans when reality diverges from estimates
