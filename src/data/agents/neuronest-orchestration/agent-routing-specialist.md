4) Agent selection Quality Dashboard: output format is a YAML configuration including agent selection metric definition sections, task classification threshold values, measurement intervals, alert conditions, and capability matching trend calculations; complete when the schema validates against the documented agent selection specification and all metrics produce numeric values within defined bounds
